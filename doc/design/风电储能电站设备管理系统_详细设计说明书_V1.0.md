# 1 文档概述
## 1.1 文档目的
本文档为**哈林格尔风电储能电站设备管理系统**软件详细设计说明书，完全贴合需求：CSV批量导入设备、手动增删设备、一键打印设备树、温度告警快速溯源。
明确系统**孩子兄弟多叉树+哈希索引**存储结构、哈希索引算法、CSV文件IO逻辑、全部函数接口、程序运行流程，是编码、单元测试、答辩唯一技术依据。

## 1.2 项目原始需求
### 1.2.1 设备层级关系（树形结构）
储能总站根节点
├─ 箱变(XB) 1~多台
│  ├─ PCS储能变流器(PCS) 1~多台
│  │  ├─ BMS电池管理系统(BMS) 一对一PCS
│  │  │  ├─ PCS储能仓(PCSC) 多仓
│  │  │  │  ├─ 电池模组(BMSMZ) 多模组
│  │  │  │  │  ├─ 模组电芯(MZDX) 最多30000个（温度告警核心对象）

### 1.2.2 核心业务需求
1. 读取`dev.csv`设备信息文件，一键批量导入全部设备，自动构建父子树形关系；
2. 支持手动新增单台设备、手动删除指定设备；
3. 一键打印完整层级设备树，层级缩进直观展示；
4. 电芯温度超过告警阈值时，快速定位完整上级设备链路，溯源故障位置；
5. 程序退出时，将内存中修改后的全部设备数据覆盖写入CSV文件，持久化保存。

### 1.3 适用范围
Ubuntu22.04 + C语言(GCC)开发环境，覆盖全部源码、文件操作、内存树形存储、交互菜单。

# 2 系统整体概要设计
## 2.1 运行环境
- 虚拟机：VMware Ubuntu 64位 22.04
- 编译器：gcc -Wall -g（开启警告+调试符号）
- 编辑器：VS Code（C/C++插件）
- 版本管理：Git + GitHub远程仓库
- 数据文件：`data/dev.csv`（数据源+持久化文件）

## 2.2 整体三层分层架构（低耦合）
1. **底层工具层**：哈希索引、内存节点创建/销毁、CSV字符串分割、文件读写IO；
2. **数据存储层**：哈希表加速ID查找 + 孩子兄弟多叉树存储设备层级，统一DevManager管理全部资源；
3. **业务交互层**：设备新增/删除、树形打印、告警筛选、控制台菜单交互。

## 2.3 整体运行流程
1. 程序启动：创建DevManager管理器 → 读取`dev.csv`导入所有设备，自动构建父子树、填充哈希索引；
2. 循环菜单：用户选择导入/新增/删除/打印整树/打印告警设备/退出；
3. 程序退出：内存设备数据覆盖写入`dev.csv` → 调用销毁函数释放全部堆内存，安全退出。

## 3.3 CSV文件标准字段规范
文件基础信息：数据源/持久化文件 `data/dev.csv`，编码 UTF-8
### 固定表头顺序（不可调换）
dev_id,dev_type,dev_name,parent_id,temperature

### 字段约束明细表
| 字段名 | 数据类型 | 是否必填 | 业务说明、单位、空值规则 |
|--------|----------|----------|--------------------------|
| dev_id | 字符串 | 是 | 设备唯一编码，系统自动生成，哈希检索主键；全局不可重复 |
| dev_type | 整型 | 是 | 对应DevType枚举数字0~7；7代表电芯，仅电芯启用温度检测 |
| dev_name | 字符串 | 是 | 设备自定义名称，最长64字符 |
| parent_id | 字符串 | 是 | 父设备dev_id；根电站DEV_DZ固定父ID填root |
| temperature | float | 否 | 设备温度，单位℃；仅DEV_CELL有效，其余设备填空；超过ALARM_TEMP触发告警 |

### 完整标准CSV样例（可直接复制测试）
```csv
dev_id,dev_type,dev_name,parent_id,temperature
DZ001,0,哈林格尔储能总站,root,
XB001,1,一号箱变,DZ001,
PCS001,2,一号PCS变流器,XB001,
CELL0001,7,A模组01电芯,MZDX001,28.5
CELL0002,7,A模组02电芯,MZDX001,62.0
```

### CSV特殊解析规则补充
1. 字段内容包含英文逗号、换行时，必须使用英文双引号包裹整段内容；
2. temperature仅DEV_CELL类型设备填充有效数值，其余设备留白；
3. 读取CSV时自动判断设备类型，非电芯忽略温度字段。

## 3.4 核心数据结构（孩子兄弟多叉树 + 哈希索引 + 全局管理器 inc/data_struct.h）
### 3.4.1 单设备树节点 DevNode（孩子兄弟表示法，带父指针快速溯源告警）
```c
typedef struct DevNode
{
    char dev_id[ID_MAX_LEN];     // 设备唯一编号，哈希检索主键
    char dev_name[NAME_MAX_LEN]; // 设备自定义名称
    DevType type;                // 设备分类枚举
    float temp;                  // 温度数据，仅DEV_CELL生效
    int has_temp;                // 标记：1=电芯带温度采集 0=其余设备无测温
    struct DevNode* parent;      // 父设备指针，告警向上追溯完整路径
    struct DevNode* child;       // 当前设备第一个子节点
    struct DevNode* brother;     // 同级兄弟节点
} DevNode;
```

### 3.4.2 哈希索引表 HashTable
作用：存储所有设备节点指针，通过dev_id快速计算下标查找，避免全树递归遍历
```c
typedef struct HashTable
{
    DevNode* bucket[HASH_TABLE_SIZE];
} HashTable;
```

### 3.4.3 全局资源管理器 DevManager（统一收拢项目全部内存资源）
```c
typedef struct DevManager
{
    DevNode* root;                          // 设备树根节点（电站总站DEV_DZ）
    HashTable* hash_table;                  // 哈希索引表
    // 各类型设备自增计数器，顺序严格匹配DevType枚举，用于自动生成唯一dev_id
    int cnt_dz,    // DEV_DZ 电站总站
        cnt_xb,    // DEV_XB 箱变
        cnt_pcs,   // DEV_PCS PCS变流器
        cnt_bms;   // DEV_BMS BMS管理系统
    int cnt_pcsc,  // DEV_PCSC 储能仓
        cnt_bmsmz, // DEV_BMSMZ 电池模组
        cnt_mzdx,  // DEV_MZDX 模组单元
        cnt_cell;  // DEV_CELL 电芯
} DevManager;
```

# 4 各模块详细设计（落地可直接编码，完全匹配头文件声明）
## 4.1 哈希索引模块 hash_table.c / data_struct.h
### 4.1.1 模块作用
1. 根据设备dev_id字符串计算哈希桶下标；
2. 哈希表创建、销毁、节点插入、按ID删除；
3. 根据设备ID直接返回DevNode*指针，极速定位设备，用于新增、删除、告警溯源。
### 4.1.2 核心接口
```c
// 根据设备ID计算哈希桶下标
int HashCalc(const char* dev_id);
// 新建空哈希表
HashTable* CreateHashTable();
// 释放哈希表所有桶内存
void DestroyHashTable(HashTable* table);
// 将设备节点插入哈希表，ID重复返回ERR_ID_DUPLICATE
int HashInsertNode(HashTable* table, DevNode* node);
// 根据设备ID删除哈希内对应节点
int HashDelNode(HashTable* table, const char* dev_id);
// 根据ID快速查找设备节点，无匹配返回NULL
DevNode* HashFindNode(DevManager* manager, const char* target_id);
```

## 4.6 主程序交互模块 main.c
### 4.6.1 模块功能
控制台循环菜单，串联所有模块，控制程序启动、运行、退出全流程。
### 4.6.2 主流程伪代码（落地直接写）
```c
int main(void)
{
    // 1. 创建全局设备管理器
    DevManager* manager = CreateDevManager();
    if(manager == NULL)
    {
        printf("内存分配失败！\n");
        return -1;
    }

    // 2. 启动自动加载CSV设备数据
    int ret = LoadCsvData(manager, "data/dev.csv");
    if(ret != RET_OK)
        printf("CSV文件加载失败，无初始设备数据\n");

    int select = 0;
    while(1)
    {
        // 打印功能菜单
        printf("=====风电储能设备管理系统=====\n");
        printf("1. 手动新增设备\n");
        printf("2. 手动删除设备\n");
        printf("3. 打印完整设备树\n");
        printf("4. 查看温度异常告警电芯\n");
        printf("0. 退出程序（自动保存数据）\n");
        printf("=============================\n");
        printf("请输入功能序号：");
        scanf("%d", &select);

        if(select == 0)
            break;  // 退出循环，执行保存

        // 根据选择调用对应函数
        switch(select)
        {
            case 1: 新增设备交互逻辑; break;
            case 2: 删除设备交互逻辑; break;
            case 3: PrintWholeDevTree(manager); break;
            case 4: PrintAllAlarmCell(manager); break;
            default: printf("输入序号错误！\n");
        }
    }

    // 3. 退出前持久化数据到CSV
    SaveDataToCsv(manager, "data/dev.csv");
    printf("数据已保存至dev.csv，程序退出\n");

    // 4. 释放全部内存
    DestroyDevManager(manager);
    return 0;
}
```

# 5 异常与容错设计（编码必写）
## 5.1 全部异常场景
1. 文件异常：`dev.csv`不存在、文件权限不足、读写失败；
2. 内存异常：malloc分配管理器、哈希表、设备节点内存失败；
3. 参数异常：新增设备父ID不存在、空设备名、设备ID重复；
4. 操作异常：删除不存在的设备；
5. 数据异常：CSV字段缺失、温度数值越界、父子循环依赖。

## 5.2 统一处理规则
1. 文件读写失败：打印提示文字，返回`ERR_FILE_ERR`，不中断菜单循环；
2. 内存分配失败：直接终止当前操作，返回`ERR_MALLOC_FAIL`；
3. 查找设备不存在：提示用户，返回`ERR_PARENT_NOT_FOUND`；
4. 程序无论正常/异常退出，都会执行`SaveDataToFile`保存数据，防止丢失；
5. 程序结束统一调用`DestroyDevManager`释放所有堆内存，无内存泄漏。

## 9.2 术语说明
1. 孩子兄弟多叉树：每个节点保存父指针、第一个子节点、同级兄弟节点，高效存储不限层级的设备树形结构；
2. CSV：逗号分隔文本，作为设备数据源与持久化载体；
3. DEV_CELL电芯：温度告警检测核心设备类型；
4. 哈希索引：通过设备唯一ID快速定位节点，避免递归全树遍历；
5. DevManager全局管理器：统一管理树根、哈希表、各类型设备计数器，统一初始化与销毁；
6. 持久化：程序退出将内存树形数据写入本地CSV文件，下次启动可完整恢复设备结构。
