# 1 文档概述
## 1.1 文档目的
本文档为**哈林格尔风电储能电站设备管理系统**软件详细设计说明书，完全贴合需求：CSV批量导入设备、手动增删设备、一键打印设备树、温度告警快速溯源。
明确系统树形存储结构、哈希索引算法、CSV文件IO逻辑、全部函数接口、程序运行流程，是编码、单元测试、答辩唯一技术依据。

## 1.2 项目原始需求
### 1.2.1 设备层级关系（树形结构）
储能总站根节点
├─ 箱变(XB) 1~多台
│  ├─ PCS储能变流器(PCS) 1~多台
│  │  ├─ BMS电池管理系统(BMS) 一对一PCS
│  │  │  ├─ PCS储能仓(PCSC) 多仓
│  │  │  │  ├─ 电池模组(BMSMZ) 多模组
│  │  │  │  │  ├─ 模组电芯(MZDX) 最多30000个（温度告警核心对象）

### 1.2.2 核心业务需求
1. 读取`dev.csv`设备信息文件，一键批量导入全部设备，自动构建父子树形关系；
2. 支持手动新增单台设备、手动删除指定设备；
3. 一键打印完整层级设备树，层级缩进直观展示；
4. 电芯温度异常（alarm_code≠0）时，快速定位完整上级设备链路，溯源故障位置；
5. 程序退出时，将内存中修改后的全部设备数据覆盖写入CSV文件，持久化保存。

### 1.3 适用范围
Ubuntu22.04 + C语言(GCC)开发环境，覆盖全部源码、文件操作、内存树形存储、交互菜单。

# 2 系统整体概要设计
## 2.1 运行环境
- 虚拟机：VMware Ubuntu 64位 22.04
- 编译器：gcc -Wall -g（开启警告+调试符号）
- 编辑器：VS Code（C/C++插件）
- 版本管理：Git + GitHub远程仓库
- 数据文件：`data/dev.csv`（数据源+持久化文件）

## 2.2 整体三层分层架构（低耦合）
1. **底层工具层**：哈希索引、内存链表管理、CSV字符串分割、文件读写IO；
2. **数据存储层**：哈希+双亲孩子表示法存储设备树形结构；

3. 程序退出：内存设备数据覆盖写入`dev.csv` → 释放全部堆内存，安全退出。

### 字段约束明细表

### CSV特殊解析规则补充
1. 字段内容包含英文逗号、换行时，必须使用英文双引号包裹整段内容；
2. 数字字段（温度、soc、电压）禁止填入中文文字，无数据直接留白；
3. alarm_code 电芯温度超过阈值自动赋值非0，触发告警溯源功能。

## 3.4 核心数据结构（哈希+双亲孩子链表）
### 3.4.1 单台设备基础信息结构体 DEVINFO
```c
typedef struct dev_info
{
    char dev_name[DEV_NAME_MAX];    // 设备唯一名称（检索关键字）
    int dev_type;                   // 设备类型 enum DEV_TYPE
    char dev_desc[DEV_DESC_MAX];    // 设备描述
    char parent_name[DEV_NAME_MAX]; // 父设备名称
    float soc;                      // 剩余电量
    float voltage;                  // 电压
    float current;                  // 电流功率
    float temperature;              // 温度（告警判断依据）
    int alarm_code;                 // 告警码：0无告警，>0温度异常
    char ext_json[EXT_JSON_MAX];    // 扩展备用字段
}DEVINFO;
```

### 3.4.2 子设备链表节点 CHILD（双亲孩子表示法）
每个父设备保存所有子设备的数组下标
```c
typedef struct child_info
{
    int index;                  // 子设备在总数组中的下标
    struct child_info *pNext;
}CHILD;
```

### 3.4.3 完整设备节点 DEVNODE（设备信息+子设备链表头）
```c
typedef struct dev_node
{
    DEVINFO dev_info;
    CHILD *pChildHead;  // 当前设备所有子节点链表头
}DEVNODE;
```

### 3.4.4 全局设备管理链表 DEVLIST
存储全部设备、记录当前有效设备总数
```c
typedef struct dev_list
{
    DEVNODE *pDevArr;  // 动态数组存储所有设备节点
    int list_size;     // 当前已存在设备数量
}DEVLIST;
```

## 4.6 主程序交互模块 main.c
### 4.6.1 模块功能
控制台循环菜单，串联所有模块，控制程序启动、运行、退出全流程。
### 4.6.2 主流程伪代码（落地直接写）
```c
int main(void)
{
    // 1. 创建空设备链表
    DEVLIST *pDevList = CreateDevList();
    if(pDevList == NULL)
    {
        printf("内存分配失败！\n");
        return -1;
    }

    // 2. 启动自动加载CSV设备数据
    int ret = LoadCsvFromFile(pDevList, CSV_FILE_PATH);
    if(ret != RET_OK)
        printf("CSV文件加载失败，无初始设备数据\n");

    int select = 0;
    while(1)
    {
        // 打印功能菜单
        printf("=====风电储能设备管理系统=====\n");
        printf("1. 手动新增设备\n");
        printf("2. 手动删除设备\n");
        printf("3. 打印完整设备树\n");
        printf("4. 查看温度异常告警电芯\n");
        printf("0. 退出程序（自动保存数据）\n");
        printf("=============================\n");
        printf("请输入功能序号：");
        scanf("%d", &select);

        if(select == 0)
            break;  // 退出循环，执行保存

        // 根据选择调用对应函数
        switch(select)
        {
            case 1: 新增设备逻辑; break;
            case 2: 删除设备逻辑; break;
            case 3: PrintDevTree(pDevList); break;
            case 4: PrintAlarmCell(pDevList); break;
            default: printf("输入序号错误！\n");
        }
    }

    // 3. 退出前持久化数据到CSV
    SaveCsvToFile(pDevList, CSV_FILE_PATH);
    printf("数据已保存至dev.csv，程序退出\n");

    // 4. 释放全部内存
    DestroyDevList(&pDevList);
    return 0;
}
```

# 5 异常与容错设计（编码必写）
## 5.1 全部异常场景
1. 文件异常：`dev.csv`不存在、文件权限不足、读写失败；
2. 内存异常：malloc分配链表/子节点内存失败；
3. 参数异常：新增设备父名称不存在、空设备名；
4. 操作异常：删除不存在的设备、重复同名设备；
5. 数据异常：CSV字段缺失、温度数值越界、父子循环依赖。

## 5.2 统一处理规则
1. 文件读写失败：打印提示文字，返回`RET_FILE_ERR`，不中断菜单循环；
2. 内存分配失败：直接终止当前操作，返回失败码；
3. 查找设备不存在：提示用户，返回`RET_NOT_FOUND`；
4. 程序无论正常/异常退出，都会执行`SaveCsvToFile`保存数据，防止丢失；
5. 程序结束统一调用`DestroyDevList`释放所有堆内存，无内存泄漏。
